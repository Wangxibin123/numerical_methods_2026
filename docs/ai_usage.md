# AI 工具使用说明

按课程要求，本附录记录本项目中使用大语言模型（LLM）的方式与范围。

## 工具

- 主要：Claude（Anthropic）Opus 系列。
- 辅助：偶尔通过 ChatGPT 检索 NYC TLC 文档 / Beamer 写法。

## 使用方式

| 阶段 | 是否使用 AI | 说明 |
| ---- | -------- | ---- |
| 项目题目 / 范围拍板 | 是 | 与 AI 反复讨论后冻结到 NYC TLC + 预测—优化 |
| Python 预处理脚手架 | 是 | AI 生成第一版骨架，团队对照 TLC v2 schema 修正 |
| 清洗规则 | 否 | 阈值由团队基于数据分布手工敲定，AI 只参与写代码 |
| 北太天元 LP 矩阵构造 | 是 | AI 给出 column-major 变量排序方案，团队 hand-verify |
| 数学符号 / 公式排版 | 是 | AI 生成 LaTeX 草稿，团队定稿 |
| Beamer / PPT 模板 | 是 | AI 给出 16:9 模板，团队定制颜色与分页 |
| 实验数据分析 | 否 | 实验结果与数值由北太天元跑出来，AI 不参与解释 |
| 录音 / 视频 | 否 | 全部由人完成 |

## 责任声明

- 所有数学公式、北太天元代码与最终结论由团队成员审阅并负责。
- AI 生成内容不直接复制到正文。AI 的代码草稿都经过 hand-verify。
- 论文与展示中的结果可重现，复现命令见 [reproduce.md](reproduce.md)。
